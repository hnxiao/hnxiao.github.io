# Han Xiao's Homepage

My personal homepage: **https://hnxiao.github.io/** — this repository contains
the site's source code; all page content is rendered from the JSON / BibTeX
data files in `content/`.

The site is built on the open-source template
[fengxueguiren/Open-Academic-Homepage](https://github.com/fengxueguiren/Open-Academic-Homepage)
(MIT), which extends the original
[Laip11/academic-homepage-template](https://github.com/Laip11/academic-homepage-template)
(MIT).

Besides mine, two other homepages are also built on this template — for
reference:

- [Peng Lai](https://laip11.github.io/) — author of the original template
- [Quanmin Wei](https://weiquanmin.github.io/) — author of Open-Academic-Homepage
